# Lottie assets

These animations are stored locally so the interface does not depend on a third-party request at runtime.

- `menu-toggle.json`: two-state hamburger animation from the public LottieFiles CDN (`lf20_ubi2j831`).
- `orbit.json`: orbit animation used in the official LottieFiles player documentation (`lf20_gb5bmwlm`).
- `footer-arrow.json`: arrow animation referenced by the LottieFiles CodePen example “How to Build a Coming Soon Page With Lottie Animations” (`lf20_ojgw1ksr`).
