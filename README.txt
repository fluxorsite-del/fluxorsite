SITE FLUXOR STUDIO — INSTRUÇÕES

1. Abra o arquivo index.html no navegador para visualizar o site.
2. Edite o telefone, o e-mail, os links das redes sociais, os preços e os projetos diretamente no index.html.
3. Os estilos visuais estão no arquivo styles.css.
4. As animações, o cursor roxo e as interações estão no arquivo script.js.
5. Para publicar, envie os quatro arquivos para a pasta pública da sua hospedagem.

Todo o conteúdo visível, inclusive os textos presentes nos elementos gráficos e demonstrações, está em português.
